# 🏡 NestIQ | Real Estate AI Frontend

A sleek, glassmorphic frontend application built for the **nestIQ** real estate platform. Designed to provide users with an intuitive experience for AI-powered property valuation and advanced real estate search.

---

## 🛠️ Tech Stack

* **Framework:** React.js
* **Language:** TypeScript
* **Styling:** Tailwind CSS / CSS Modules
* **State Management:** React Context API / Zustand
* **Routing:** React Router (BrowserRouter)
* **API Integration:** Axios / Fetch (for connection with .NET Core backend)

---

## 🚀 Key Features

* **AI Valuation Engine:** Integrated search bar component for AI-driven property price requests.
* **Glassmorphic UI:** Modern, clean, and responsive design for enhanced user interaction.
* **Advanced Filtering:** Query properties by area, bedroom count, and coordinate metrics.
* **Global State Management:** Seamless routing and data flow across the application.
